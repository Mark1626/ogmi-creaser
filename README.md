# Ogmi-Creaser

Ogmi-Creaser is a tool for creating origami crease patterns. This project is a independent fork of [Jason S. Ku's](http://jasonku.mit.edu/) [Flat-Folder](https://origamimagiro.github.io/flat-folder/) with a crease pattern editor and uses it's algorithm to verify flat foldability during design. The upstream project has [example FOLD crease patterns](https://github.com/origamimagiro/flat-folder/tree/main/examples) to experiment with

Website in live here - [Ogmi-Creaser](https://mark1626.github.io/ogmi-creaser)

## Inspiration

I'm a newbie designer so I thought it useful to have flat folder available during design.
