# XP.css (vendored)

Unmodified copy of [XP.css](https://github.com/botoxparty/XP.css) v0.2.6
(MIT, see `LICENSE`), taken from the `dist/` folder of the npm tarball
<https://registry.npmjs.org/xp.css/-/xp.css-0.2.6.tgz>
(integrity `sha512-v0qUB4wOvyXIMLNid5bIpm+0n5aL4i8wE5dqJH8LNVxE04PxUUxjwf2rNzengegUIK03XC4vbfLVCPAfMLtuqA==`).

It is copied in rather than installed so the page keeps working with no build
step, no package manager and no network access. `XP.css` loads the font files
next to it by relative path, so keep them together.

Local layout and fixes live in `../../style.css`; do not edit these files.
To upgrade, replace every file here from the new release's `dist/` folder.
